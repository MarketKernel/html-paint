Редактор зображень у дусі Paint.NET, що вміщується в **один самодостатній HTML-файл**. Шари,
виділення, корекція та ефекти, історія, якою можна гортати назад — і нічого не йде в мережу:
файл відкривається з диска, працює офлайн і нічого не завантажує з інтернету.

Інтерфейс доступний 17 мовами (Вигляд → Мова…) — англійською, китайською, гінді, іспанською,
французькою, арабською, бенгальською, португальською, російською, урду, індонезійською,
німецькою, японською, маратхі, телугу, турецькою та українською; арабська та урду — справа
наліво. Є світла й темна теми, а інтерфейс підлаштовується як під екран телефона, так і під
екран комп'ютера.

## Користування

Завантажте `paint-v<version>.html` зі сторінки
[релізів](https://github.com/MarketKernel/html-paint/releases) або зберіть його самостійно
(нижче) і відкрийте у браузері — Chrome, Edge, Firefox чи Safari. Цей файл і є всією
програмою: його можна копіювати куди завгодно, надсилати поштою, класти на флешку.

Або відкрийте його на [GitHub Pages](https://marketkernel.github.io/html-paint/) і встановіть
як застосунок (кнопка встановлення в адресному рядку; на iPhone — Поділитися → На екран
«Домівка»). Після цього він працює офлайн і оновлюється сам під час наступного запуску, якщо
вийшла нова версія.

У Chrome і Edge на комп'ютері встановлений застосунок відкриває й зображення із системи:
виберіть його у «Відкрити за допомогою» для файлу PNG, JPEG, WebP, GIF, BMP, ICO, AVIF,
SVG чи OpenRaster або зробіть його типовим. Кожен файл відкривається у власному вікні, а
«Зберегти» записує назад у нього.

Перетягніть зображення у вікно, щоб відкрити його або додати як новий шар.

## Що він уміє

**Інструменти** — у кожного своя клавіша; повторне натискання перемикає на наступний
інструмент тієї ж клавіші.

| Інструмент | Клавіша | |
|---|---|---|
| Прямокутне й овальне виділення, ласо | S | Shift додає до виділення, Alt віднімає, обидва разом — перетин |
| Чарівна паличка | W | Схожі кольори, суміжні або по всьому зображенню, за допуском |
| Переміщення виділеного | M | Перетягування переміщує, маркери масштабують, за межами — обертає; Enter застосовує, Esc повертає назад |
| Переміщення виділення | M | Лише контур; стрілки зсувають на піксель |
| Масштаб, рука | Z, H | Пробіл або середня кнопка переміщують полотно з будь-яким інструментом; ⌘/Ctrl + колесо або жест пальцями масштабує |
| Пензель | B | Ширина, жорсткість, непрозорість, згладжування; тиск пера |
| Олівець | P | Окремі пікселі |
| Гумка | E | |
| Розпилювач | A | Розпилює, доки натиснута кнопка |
| Заливка | F | Допуск, суміжна або загальна, шар або все зображення |
| Градієнт | G | Лінійний, відбитий, радіальний, конічний; від основного кольору до додаткового |
| Піпетка | K | Із шару або із зображення; може повертати до попереднього інструмента |
| Штамп | L | Ctrl+клац (⌘+клац) вибирає джерело |
| Текст | T | Вводиться на місці; шрифт, розмір, жирний, курсив, підкреслення, вирівнювання |
| Лінія, прямокутник, еліпс | O | Контур, заливка або обидва; штрихи, заокруглені кути, стрілки; Shift обмежує пропорції |
| Крива | O | Крива Без'є: витягніть лінію, вигніть її за дві контрольні точки; Enter застосовує |

Ліва кнопка малює основним кольором, права — додатковим. X міняє їх місцями, D скидає їх на
чорний і білий, `[` і `]` змінюють розмір пензля.

**Шари** — додавання, видалення, дублювання, об'єднання з нижнім, зміна порядку (перетягуванням
у панелі), приховування, перейменування; непрозорість і 17 режимів накладання (множення,
екран, перекриття, м'яке світло, різниця, відтінок…).

**Редагування** — скасування та повторення кожного кроку, з панеллю «Історія» для переходу
до будь-якого з них; вирізання, копіювання, копіювання зведеного; вставлення в шар (як
плаваюче, щоб потім розмістити), у новий шар або як нове зображення — у тому числі із
системного буфера обміну; виділити все, зняти виділення, інвертувати виділення; стерти або
залити виділене.

**Зображення** — обрізання за виділенням, зміна розміру (згладжена або найближчий сусід),
розмір полотна з прив'язкою, віддзеркалення, обертання, зведення шарів.

**Корекція** — авторівні, чорно-біле, яскравість і контраст, відтінок і насиченість,
інвертування кольорів, постеризація, сепія, поріг.

**Ефекти** — розмиття за Гаусом, розмиття в русі, різкість, шум, пікселізація, тиснення,
виділення країв, олійний живопис, віньєтка. Ті, що мають налаштування, показують попередній
перегляд прямо на зображенні під час зміни значень. Корекція та ефекти діють лише в межах
виділення, якщо воно є.

**Файли** — відкриваються PNG, JPEG, WebP, GIF, BMP, SVG та інші формати; PNG, JPEG і WebP
зберігають зображення зведеним. **OpenRaster (.ora)** зберігає шари з їхніми назвами,
непрозорістю, видимістю та режимами накладання — його також відкривають GIMP, Krita і
MyPaint. Там, де браузер дозволяє сторінці записувати файли (Chrome, Edge), ⌘S / Ctrl+S
зберігає назад у відкритий файл; в інших випадках збереження відбувається як завантаження
файлу.

## Збирання

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # пересобирає при кожній зміні, без мінімізації
npm run check        # перевірка типів, модульні тести, збирання, тести в браузері
npm run shots        # знімки екрана головних екранів у shots/
```

Потрібен Node 20 або новіший. Тести в браузері керують зібраною сторінкою в локальному
Chrome через протокол DevTools; якщо Chrome встановлено в нестандартному місці, вкажіть
`CHROME=/path/to/chrome`.

Збирання також створює `build/pages/`: ту саму сторінку як PWA — маніфест, іконки та service
worker. PNG-іконки зберігаються в `assets/pwa/`; після зміни іконки в `src/app/icons.ts`
команда `node tools/icons.mjs` перемальовує їх заново (за допомогою Chrome).

## Релізи

Публікацією займається GitHub Actions:

- кожен пуш у `main` тестується й розгортається на GitHub Pages (Settings → Pages → Source:
  GitHub Actions, один раз);
- тег `v<version>` збирає, тестує та публікує реліз із `paint-v<version>.html` і його
  `SHA256SUMS.txt`. Тег має збігатися з версією в `package.json`:

  ```sh
  npm version 0.2.0      # записує package.json, робить коміт, ставить тег v0.2.0
  git push --follow-tags
  ```

## Структура

```
src/
  core/            без DOM, виконується в Node під час тестів
    color.ts       RGB, HSV, HSL, hex; колірна відстань; палітра
    raster.ts      заливка (відром, паличкою), лінії олівця, контури масок, прямокутники
    filters.ts     корекція та ефекти, на простих масивах пікселів
    zip.ts, ora.ts ZIP і stack.xml формату OpenRaster
    i18n.ts        t(), tn(), N_()
  app/             сторінка
    template.html, styles.css
    main.ts        запускає все
    app.ts         стан: документ, історія, кольори, налаштування, живий попередній перегляд
    document.ts    зображення та його шари
    selection.ts   виділення як маски
    history.ts     скасування та повторення
    view.ts        робоча область: масштаб, прокрутка, малювання, введення вказівником
    tools/         по одному файлу на кожен вид інструмента
    commands.ts    меню та клавіатурні скорочення
    ops.ts         команди «Редагування», «Зображення» та «Шари»
    effects.ts     меню «Корекція» та «Ефекти»
    io.ts          відкриття та збереження
    prompts.ts     діалоги за командами
    ui/            рядок меню, панель інструментів, панелі, діалоги
  locales/         ru.json, uk.json — ключі це англійський текст
  pwa/sw.js        service worker збірки для GitHub Pages
assets/pwa/        PNG-іконки PWA
tests/             модульні тести (Node) і тест у браузері (tests/app.mjs)
tools/             load.mjs (компілює src/ для тестів), i18n.mjs (шукає рядки),
                   icons.mjs (малює assets/pwa/)
build.mjs          збирає все в build/paint.html і build/pages/
.github/workflows/ тести, розгортання на GitHub Pages, релізи за тегами v*
```

## Переклади

Кожен рядок інтерфейсу — це `t('English text')` (або `N_('…')` там, де таблиця будується до
того, як відома мова) із звичайним рядковим літералом. `node tools/i18n.mjs` показує, чого
бракує в кожному словнику або що в ньому вже зайве; `npm test` не проходить, доки вони не
збігаються. Значення для множини — це об'єкт із формою для кожної категорії множини мови
(`one`, `few`, `many`, `other`…). Нова мова — це новий файл `src/locales/<code>.json` і рядок
у `src/app/language.ts`.

Цей README перекладено у файлах `docs/readme/README.<code>.md`; перелік мов між мітками
`<!-- languages -->` однаковий у кожному з них.
