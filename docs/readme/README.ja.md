Paint.NET の流れをくむ画像編集ソフトで、**単一の HTML ファイル**としてまとまっています。レイヤー、選択範囲、色調補正、エフェクト、いつでも戻れる履歴を備えながら、何もこのページの外には出ません。ディスクから開き、オフラインで動作し、ネットワークへは一切アクセスしません。

インターフェースは17言語に対応しています（表示 → 言語…）——英語、中国語、ヒンディー語、スペイン語、フランス語、アラビア語、ベンガル語、ポルトガル語、ロシア語、ウルドゥー語、インドネシア語、ドイツ語、日本語、マラーティー語、テルグ語、トルコ語、ウクライナ語。アラビア語とウルドゥー語は右から左に表示されます。ライトテーマとダークテーマがあり、スマートフォンの画面にもデスクトップの画面にも収まります。

## 使い方

[リリースページ](https://github.com/MarketKernel/html-paint/releases)から `paint-v<version>.html` をダウンロードするか、自分でビルドして（下記参照）、ブラウザ（Chrome、Edge、Firefox、Safari）で開いてください。このファイル1つがプログラムのすべてです。どこへでもコピーでき、メールで送ることも、USBメモリに入れることもできます。

あるいは [GitHub Pages](https://marketkernel.github.io/html-paint/) で開いて、アプリとしてインストールすることもできます（アドレスバーのインストールボタンから。iPhone では 共有 → ホーム画面に追加）。インストール後はオフラインで動作し、新しい版が公開されると次回の起動時に自動で更新されます。

画像をウィンドウにドロップすると、開くか、レイヤーとして追加できます。

## できること

**ツール** — それぞれ1つのキーに割り当てられており、同じキーをもう一度押すと同じキーの次のツールに切り替わります。

| ツール | キー | |
|---|---|---|
| 矩形選択・楕円選択・投げなわ選択 | S | Shift で選択範囲に追加、Alt で除外、両方で交差 |
| 自動選択 | W | 近い色を、隣接範囲または画像全体から、許容誤差で選択 |
| 選択ピクセルの移動 | M | ドラッグで移動、ハンドルで拡大縮小、外側で回転。Enter で適用、Esc で元に戻す |
| 選択範囲の移動 | M | 輪郭のみを移動（ピクセルはそのまま）。矢印キーで微調整 |
| ズーム・手のひら | Z、H | スペースキーまたは中ボタンは、どのツールでもスクロールに使用可能。⌘/Ctrl + ホイールやピンチで拡大縮小 |
| ブラシ | B | 太さ、硬さ、不透明度、アンチエイリアス。筆圧に対応 |
| 鉛筆 | P | 1ピクセル単位で描画 |
| 消しゴム | E | |
| エアブラシ | A | ボタンを押している間、吹き付ける |
| バケツ | F | 許容誤差、隣接または画像全体、レイヤー単位か画像全体かを選択 |
| グラデーション | G | 線形、反射、放射状、円錐状。描画色 → 背景色 |
| スポイト | K | レイヤーまたは画像から色を取得。前のツールに戻ることも可能 |
| スタンプ | L | Ctrl+クリック（⌘+クリック）でコピー元を指定 |
| テキスト | T | その場に入力。フォント、サイズ、太字、斜体、下線、配置 |
| 直線・四角形・楕円 | O | 輪郭線、塗りつぶし、またはその両方。線種、角の丸め、矢印。Shift で制約 |
| 曲線 | O | ベジェ曲線。線をドラッグで引き出し、2つの制御点で曲げる。Enter で適用 |

左ボタンは描画色で、右ボタンは背景色で描画します。X で色を入れ替え、D で黒と白に戻し、`[` と `]` でブラシサイズを変更します。

**レイヤー** — 追加、削除、複製、下のレイヤーと結合、並べ替え（パネル内でドラッグ）、非表示、名前の変更。不透明度と17種類の描画モード（乗算、スクリーン、オーバーレイ、ソフトライト、差の絶対値、色相…）。

**編集** — すべての操作の取り消しとやり直し。履歴パネルから任意の時点に移動できます。切り取り、コピー、結合してコピー。レイヤーへの貼り付け（配置できるようフロート状態になる）、新しいレイヤーへの貼り付け、新しい画像としての貼り付け——システムのクリップボードからも可能。すべて選択、選択解除、選択範囲の反転、選択範囲の消去または塗りつぶし。

**画像** — 選択範囲で切り抜き、サイズ変更（スムーズまたはニアレストネイバー）、アンカー付きのキャンバスサイズ変更、反転、回転、画像の統合。

**色調補正** — 自動レベル補正、白黒、明るさとコントラスト、色相と彩度、色の反転、ポスタリゼーション、セピア、しきい値。

**エフェクト** — ガウスぼかし、モーションブラー、シャープ、ノイズ、モザイク、エンボス、エッジ検出、油絵風、ビネット。設定のあるものは、変更するとその場で画像にプレビューされます。色調補正とエフェクトは、選択範囲があればそれに従います。

**ファイル** — PNG、JPEG、WebP、GIF、BMP、SVG などを開けます。PNG、JPEG、WebP は画像を統合して保存します。**OpenRaster（.ora）**はレイヤーを、その名前、不透明度、表示状態、描画モードごと保持します——GIMP、Krita、MyPaint でも開けます。ブラウザがページによるファイル書き込みを許可している場合（Chrome、Edge）は、⌘S / Ctrl+S で開いていたファイルに上書き保存します。それ以外の場合はダウンロードになります。

## ビルド

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # 変更のたびに再ビルド（非圧縮）
npm run check        # 型チェック、ユニットテスト、ビルド、ブラウザテスト
npm run shots         # 主要画面のスクリーンショットを shots/ に保存
```

Node 20 以降が必要です。ブラウザテストは、ビルドしたページをローカルの Chrome 上で DevTools プロトコル経由で操作します。Chrome が特殊な場所にある場合は `CHROME=/path/to/chrome` を設定してください。

ビルドでは `build/pages/` も生成されます。これは同じページを PWA 化したもので、マニフェスト、アイコン、サービスワーカーを含みます。PNG アイコンは `assets/pwa/` に保存されていて、`src/app/icons.ts` のアイコンを変更したら、`node tools/icons.mjs` を実行すると（Chrome を使って）再描画されます。

## リリース

公開は GitHub Actions が行います。

- `main` へのすべての push はテストされ、GitHub Pages にデプロイされます（Settings → Pages → Source: GitHub Actions を一度設定しておく）。
- `v<version>` タグを付けると、ビルドとテストの上で、`paint-v<version>.html` とその `SHA256SUMS.txt` を含むリリースが公開されます。タグは `package.json` のバージョンと一致している必要があります。

  ```sh
  npm version 0.2.0      # package.json を書き換え、コミットし、v0.2.0 のタグを付ける
  git push --follow-tags
  ```

## 構成

```
src/
  core/            DOM を持たず、テストは Node 上で実行
    color.ts       RGB、HSV、HSL、16進数。色の距離、パレット
    raster.ts      塗りつぶし（バケツ、自動選択）、鉛筆の線、マスクの輪郭、矩形
    filters.ts     色調補正とエフェクト（単純なピクセル配列に対して処理）
    zip.ts, ora.ts ZIP と OpenRaster の stack.xml
    i18n.ts        t()、tn()、N_()
  app/             ページ本体
    template.html, styles.css
    main.ts        すべての起点
    app.ts         状態: ドキュメント、履歴、色、設定、ライブプレビュー
    document.ts    画像とそのレイヤー
    selection.ts   マスクとしての選択範囲
    history.ts     取り消しとやり直し
    view.ts        作業領域: ズーム、スクロール、描画、ポインター入力
    tools/         ツールの種類ごとに1ファイル
    commands.ts    メニューとキーボードショートカット
    ops.ts         編集・画像・レイヤーの各コマンド
    effects.ts     色調補正とエフェクトのメニュー
    io.ts          開く・保存する処理
    prompts.ts     コマンドの背後にあるダイアログ
    ui/            メニューバー、ツールボックス、パネル、ダイアログ
  locales/         ru.json、uk.json — 英語のテキストをキーとする
  pwa/sw.js        GitHub Pages ビルドのサービスワーカー
assets/pwa/        PWA の PNG アイコン
tests/             ユニットテスト（Node）とブラウザテスト（tests/app.mjs）
tools/             load.mjs（テスト用に src/ をコンパイル）、i18n.mjs（文字列を検出）、
                   icons.mjs（assets/pwa/ を描画）
build.mjs          build/paint.html と build/pages/ にまとめてビルド
.github/workflows/ テスト、GitHub Pages デプロイ、v* タグからのリリース
```

## 翻訳

表示されるすべての文字列は `t('English text')`（言語が決まる前にテーブルを構築する場合は `N_('…')`）として、プレーンな文字列リテラルで書かれています。`node tools/i18n.mjs` は各辞書に不足している文字列と、もう使われていない文字列を一覧表示します。`npm test` は、それらが一致するまで失敗します。複数形の値は、その言語の複数形カテゴリ（`one`、`few`、`many`、`other`…）ごとの形を持つオブジェクトです。新しい言語を追加するには、新しい `src/locales/<code>.json` と `src/app/language.ts` への1行の追加が必要です。

この README は `docs/readme/README.<code>.md` として翻訳されています。`<!-- languages -->` の間にある言語一覧は、どの言語版でも同じです。
