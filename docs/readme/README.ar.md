محرر صور على غرار Paint.NET، في **ملف HTML واحد مستقل**. طبقات، تحديدات، تعديلات وتأثيرات،
وسجلّ خطوات يمكن التراجع خلاله خطوة بخطوة — ولا يغادر هذه الصفحة أي شيء: فهو يُفتح من القرص،
ويعمل دون اتصال بالإنترنت، ولا يحمّل شيئًا من الشبكة.

تتوفر الواجهة بـ17 لغة (عرض ← اللغة…) — الإنجليزية، والصينية، والهندية، والإسبانية،
والفرنسية، والعربية، والبنغالية، والبرتغالية، والروسية، والأردية، والإندونيسية، والألمانية،
واليابانية، والماراثية، والتيلوغوية، والتركية، والأوكرانية؛ والعربية والأردية من اليمين إلى
اليسار. ويأتي بمظهر فاتح أو داكن، ويلائم شاشة الهاتف كما يلائم شاشة الحاسوب.

## استخدامه

نزّل `paint-v<version>.html` من صفحة
[الإصدارات](https://github.com/MarketKernel/html-paint/releases)، أو ابنِه بنفسك (أدناه)،
ثم افتحه في متصفح — Chrome أو Edge أو Firefox أو Safari. هذا الملف الواحد هو البرنامج كله:
يمكن نسخه إلى أي مكان، وإرساله بالبريد، أو وضعه على ذاكرة USB.

أو افتحه على [GitHub Pages](https://marketkernel.github.io/html-paint/) وثبّته كتطبيق (زر
التثبيت في شريط العنوان؛ أو مشاركة ← إضافة إلى الشاشة الرئيسية على آيفون). بعدها يعمل دون
اتصال بالإنترنت، ويحدّث نفسه تلقائيًا عند أول تشغيل بعد نشر إصدار جديد.

في Chrome وEdge على الحاسوب يفتح التطبيق المثبّت الصور من النظام أيضًا: اختره من «فتح
باستخدام» لملف PNG أو JPEG أو WebP أو GIF أو BMP أو ICO أو AVIF أو SVG أو OpenRaster، أو
اجعله التطبيق الافتراضي. يُفتح كل ملف في نافذة خاصة به، والحفظ يكتب إليه مباشرة.

أفلت صورة على النافذة لفتحها، أو لإضافتها كطبقة.

## ما يفعله

**الأدوات** — مفتاح واحد لكل أداة؛ الضغط عليه مجددًا ينتقل إلى الأداة التالية على المفتاح نفسه.

| الأداة | المفتاح | |
|---|---|---|
| تحديد مستطيل وبيضاوي وبالحبل | S | يضيف Shift إلى التحديد، ويطرح Alt، وكلاهما معًا يحدد التقاطع |
| العصا السحرية | W | ألوان متشابهة، متجاورة أو على كامل الصورة، حسب درجة التفاوت |
| نقل البكسلات المحددة | M | اسحب للنقل، والمقابض للتحجيم، ومن الخارج للتدوير؛ Enter للتطبيق، Esc للتراجع |
| نقل التحديد | M | الحدود فقط؛ تحرّكه مفاتيح الأسهم بدقة |
| التكبير والتحريك | Z، H | يحرّك أي أداة بمفتاح المسافة أو الزر الأوسط؛ ويكبّر ⌘/Ctrl + العجلة أو القرص |
| الفرشاة | B | العرض، الصلابة، العتامة، تنعيم الحواف؛ وضغط القلم |
| قلم رصاص | P | بكسلات مفردة |
| ممحاة | E | |
| فرشاة الهواء | A | ترش طالما الزر مضغوطًا |
| دلو الطلاء | F | التفاوت، متجاور أو على كامل الصورة، للطبقة أو للصورة كلها |
| تدرج | G | خطي، منعكس، شعاعي، مخروطي؛ من اللون الأساسي إلى الثانوي |
| القطّارة | K | من الطبقة أو من الصورة؛ يمكن العودة إلى الأداة السابقة |
| ختم الاستنساخ | L | يحدد Ctrl+نقرة (⌘+نقرة) المصدر |
| نص | T | يُكتب في مكانه؛ الخط، الحجم، عريض، مائل، تسطير، المحاذاة |
| خط ومستطيل وبيضاوي | O | إطار أو تعبئة أو كلاهما؛ شرطات، زوايا مدورة، أسهم؛ يقيّد Shift الشكل |
| منحنى | O | منحنى بيزيه: اسحب خطًا ثم اثنِه بنقطتي التحكم؛ Enter للتطبيق |

الزر الأيسر يرسم باللون الأساسي، والأيمن بالثانوي. X يبدّلهما، وD يعيدهما إلى الأسود
والأبيض، و`[` و`]` يغيّران حجم الفرشاة.

**الطبقات** — إضافة، حذف، تكرار، دمج مع السفلية، إعادة ترتيب (بالسحب في اللوحة)، إخفاء،
إعادة تسمية؛ العتامة و17 وضع مزج (ضرب، شاشة، تراكب، ضوء ناعم، الفرق، تدرج لوني…).

**التحرير** — تراجع وإعادة لكل خطوة، مع لوحة سجلّ للقفز إلى أي منها؛ قص، نسخ، نسخ مدمج؛
لصق في الطبقة (عائمًا، لوضعه)، أو في طبقة جديدة أو كصورة جديدة — ومن حافظة النظام أيضًا؛
تحديد الكل، إلغاء التحديد، عكس التحديد؛ محو التحديد أو تعبئته.

**الصورة** — اقتصاص حسب التحديد، تغيير الحجم (ناعم أو أقرب جوار)، حجم اللوحة مع نقطة
ارتكاز، القلب، التدوير، تسوية الطبقات.

**التعديلات** — تسوية تلقائية، أبيض وأسود، السطوع والتباين، التدرج اللوني والتشبع، عكس
الألوان، تفتيت الألوان، سيبيا، العتبة.

**التأثيرات** — تمويه غاوسي، تمويه الحركة، الحدة، التشويش، البكسلة، نقش بارز، كشف الحواف،
رسم زيتي، تعتيم الحواف. التأثيرات ذات الإعدادات تُعاين على الصورة أثناء تغييرها. وتلتزم
التعديلات والتأثيرات بالتحديد عند وجوده.

**الملفات** — تُفتح PNG وJPEG وWebP وGIF وBMP وSVG وغيرها؛ وتحفظ PNG وJPEG وWebP الصورة
مسوّاة. أما **OpenRaster (.ora)** فتحتفظ بالطبقات، بأسمائها وعتامتها وظهورها وأوضاع مزجها
— ويفتحها أيضًا GIMP وKrita وMyPaint. وحيث يسمح المتصفح لصفحة بكتابة الملفات (Chrome،
Edge)، يحفظ ⌘S / Ctrl+S في الملف المفتوح نفسه؛ وفي غير ذلك يكون الحفظ تنزيلًا.

## البناء

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # يعيد البناء مع كل تغيير، دون تصغير
npm run check        # فحص الأنواع، الاختبارات الوحدوية، البناء، اختبارات المتصفح
npm run shots        # لقطات شاشة للشاشات الرئيسية في shots/
```

Node 20 أو أحدث. تُشغّل اختبارات المتصفح الصفحة المبنية في Chrome محلي عبر بروتوكول
DevTools؛ اضبط `CHROME=/path/to/chrome` إن كان في مكان غير معتاد.

كما يكتب البناء `build/pages/`: الصفحة نفسها كتطبيق PWA — بيان، أيقونات، وعامل خدمة. أيقونات
PNG الخاصة به محفوظة في `assets/pwa/`؛ وبعد تغيير الأيقونة في `src/app/icons.ts`، يرسمها
`node tools/icons.mjs` من جديد (باستخدام Chrome).

## الإصدارات

يتولى GitHub Actions عملية النشر:

- كل دفعة (push) إلى `main` تُختبر وتُنشر على GitHub Pages (الإعدادات ← Pages ← المصدر:
  GitHub Actions، مرة واحدة)؛
- وسم (tag) بالشكل `v<version>` يبني، يختبر، وينشر إصدارًا يضم `paint-v<version>.html`
  وملف `SHA256SUMS.txt` الخاص به. يجب أن يطابق الوسم إصدار `package.json`:

  ```sh
  npm version 0.2.0      # يكتب package.json، وينشئ commit، ويضع وسم v0.2.0
  git push --follow-tags
  ```

## الترجمات

كل نص تعرضه الواجهة هو `t('English text')` (أو `N_('…')` حيث يُبنى جدول قبل معرفة اللغة)
بحرفية نصية بسيطة. يسرد `node tools/i18n.mjs` ما ينقص كل قاموس أو لم يعد يحتاجه؛ ويفشل
`npm test` حتى تتطابق. قيمة صيغة الجمع كائن بصيغة لكل فئة جمع في اللغة (`one`، `few`،
`many`، `other`…). واللغة الجديدة هي ملف `src/locales/<code>.json` جديد وسطر في
`src/app/language.ts`.

وهذا الملف نفسه مترجم في `docs/readme/README.<code>.md`؛ وقائمة اللغات بين علامتي
`<!-- languages -->` واحدة في كل نسخة.
