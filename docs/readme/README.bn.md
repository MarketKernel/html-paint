Paint.NET-এর আদলে তৈরি একটি ছবি সম্পাদক, **একটি স্বতন্ত্র HTML ফাইল** হিসেবে। লেয়ার, নির্বাচন,
সমন্বয় ও ইফেক্ট, এবং যেকোনো ধাপে ফিরে যাওয়ার মতো ইতিহাস — আর কিছুই এই পেজের বাইরে যায় না: এটি
ডিস্ক থেকে খোলে, অফলাইনে কাজ করে, এবং নেটওয়ার্ক থেকে কিছুই লোড করে না।

ইন্টারফেস 17টি ভাষায় আছে (দৃশ্য → ভাষা…) — ইংরেজি, চীনা, হিন্দি, স্প্যানিশ, ফরাসি, আরবি, বাংলা,
পর্তুগিজ, রুশ, উর্দু, ইন্দোনেশিয়ান, জার্মান, জাপানি, মারাঠি, তেলুগু, তুর্কি ও ইউক্রেনীয়; আরবি ও
উর্দু ডান থেকে বাম দিকে লেখা হয়। এটি হালকা বা গাঢ় থিমে পাওয়া যায়, এবং ফোনের পর্দা ও ডেস্কটপ
উভয়েই মানানসই।

## ব্যবহার করুন

[রিলিজ](https://github.com/MarketKernel/html-paint/releases) থেকে `paint-v<ভার্সন>.html`
ডাউনলোড করুন, অথবা নিজে তৈরি করুন (নিচে দেখুন), এবং ব্রাউজারে খুলুন — Chrome, Edge, Firefox বা
Safari। এই একটি ফাইলই পুরো প্রোগ্রাম: যেকোনো জায়গায় কপি করুন, মেইল করুন, বা USB স্টিকে রাখুন।

অথবা [GitHub Pages](https://marketkernel.github.io/html-paint/)-এ খুলুন এবং অ্যাপ হিসেবে
ইনস্টল করুন (ঠিকানা বারে ইনস্টল বোতাম; আইফোনে শেয়ার → হোম স্ক্রিনে যোগ করুন)। এরপর এটি অফলাইনে
কাজ করে, এবং নতুন সংস্করণ প্রকাশ পেলে পরবর্তী চালুর সময় নিজে থেকে আপডেট হয়ে যায়।

কম্পিউটারে Chrome ও Edge-এ ইনস্টল করা অ্যাপটি সিস্টেম থেকেও ছবি খোলে: PNG, JPEG, WebP,
GIF, BMP, ICO, AVIF, SVG বা OpenRaster ফাইলের জন্য «Open With» থেকে এটি বেছে নিন, অথবা
এটিকে ডিফল্ট করে দিন। প্রতিটি ফাইল নিজের আলাদা উইন্ডোতে খোলে, আর সংরক্ষণ করলে সেই ফাইলেই
লেখা হয়।

উইন্ডোর উপর একটি ছবি ফেলে দিলে সেটি খোলে, অথবা লেয়ার হিসেবে যোগ হয়।

## এটি যা করে

**টুল** — প্রতিটির নিজস্ব কী আছে; আবার চাপলে একই কী-তে পরবর্তী টুলে যায়।

| টুল | কী | |
|---|---|---|
| আয়তক্ষেত্র, উপবৃত্ত ও লাসো নির্বাচন | S | Shift নির্বাচনে যোগ করে, Alt বিয়োগ করে, দুটো একসাথে ছেদ করে |
| ম্যাজিক ওয়ান্ড | W | একই ধরনের রং, সংলগ্ন বা পুরো ছবি জুড়ে, সহনশীলতা অনুযায়ী |
| নির্বাচিত পিক্সেল সরান | M | সরাতে টেনে আনুন, হ্যান্ডল দিয়ে আকার পরিবর্তন, বাইরে থেকে ঘোরানো; Enter প্রয়োগ করে, Esc ফিরিয়ে দেয় |
| নির্বাচন সরান | M | শুধু রূপরেখা; অ্যারো কী সূক্ষ্মভাবে সরায় |
| জুম, প্যান | Z, H | যেকোনো টুলে Space বা মাঝের বোতাম প্যান করে; ⌘/Ctrl + হুইল বা পিঞ্চ জুম করে |
| পেইন্টব্রাশ | B | প্রস্থ, কঠোরতা, অস্বচ্ছতা, অ্যান্টিআলিয়াসিং; কলমের চাপ |
| পেন্সিল | P | একক পিক্সেল |
| ইরেজার | E | |
| এয়ারব্রাশ | A | বোতাম চেপে ধরলে স্প্রে করে |
| পেইন্ট বাকেট | F | সহনশীলতা, সংলগ্ন বা গ্লোবাল, লেয়ার বা পুরো ছবি |
| গ্রেডিয়েন্ট | G | লিনিয়ার, প্রতিফলিত, রেডিয়াল, কনিক্যাল; প্রধান → দ্বিতীয় রং |
| কালার পিকার | K | লেয়ার বা ছবি থেকে; আগের টুলে ফিরে যেতে পারে |
| ক্লোন স্ট্যাম্প | L | Ctrl+ক্লিক (⌘+ক্লিক) উৎস নির্বাচন করে |
| টেক্সট | T | সরাসরি লেখা যায়; ফন্ট, আকার, বোল্ড, ইটালিক, আন্ডারলাইন, সারিবদ্ধকরণ |
| রেখা, আয়তক্ষেত্র, উপবৃত্ত | O | রূপরেখা, ভরাট বা দুটোই; ড্যাশ, গোলাকার কোণা, তীরচিহ্ন; Shift সীমাবদ্ধ করে |
| বক্ররেখা | O | একটি বেজিয়ার কার্ভ: রেখা টেনে বের করুন, এর দুটি নিয়ন্ত্রণ বিন্দু দিয়ে বাঁকান; Enter প্রয়োগ করে |

বাম বোতাম প্রধান রঙে আঁকে, ডান বোতাম দ্বিতীয় রঙে। X সেগুলো অদলবদল করে, D সেগুলো কালো ও সাদায়
ফিরিয়ে দেয়, `[` ও `]` ব্রাশের আকার পরিবর্তন করে।

**লেয়ার** — যোগ, মুছে ফেলা, ডুপ্লিকেট, নিচের সাথে একত্র করা, ক্রম পরিবর্তন (প্যানেলে টেনে),
লুকানো, নাম পরিবর্তন; অস্বচ্ছতা ও 17টি ব্লেন্ড মোড (মাল্টিপ্লাই, স্ক্রিন, ওভারলে, সফট লাইট,
ডিফারেন্স, হিউ…)।

**সম্পাদনা** — প্রতিটি ধাপের পূর্বাবস্থা ও পুনরায় করা, যেকোনো ধাপে যেতে একটি ইতিহাস প্যানেল সহ;
কাটা, কপি, একত্রিত করে কপি; লেয়ারে পেস্ট (ভাসমান অবস্থায়, যাতে বসানো যায়), নতুন লেয়ারে বা নতুন
ছবি হিসেবে — সিস্টেম ক্লিপবোর্ড থেকেও; সব নির্বাচন, নির্বাচন বাতিল, নির্বাচন বিপরীত করা;
নির্বাচিত অংশ মোছা বা ভরাট করা।

**ছবি** — নির্বাচন অনুযায়ী ক্রপ, আকার পরিবর্তন (মসৃণ বা নিকটতম প্রতিবেশী), অ্যাঙ্কর সহ
ক্যানভাসের আকার, ফ্লিপ, ঘোরানো, সমতল করা।

**সমন্বয়** — অটো-লেভেল, কালো ও সাদা, উজ্জ্বলতা ও কনট্রাস্ট, হিউ ও স্যাচুরেশন, রং বিপরীত করা,
পোস্টারাইজ, সেপিয়া, থ্রেশহোল্ড।

**ইফেক্ট** — গসিয়ান ব্লার, মোশন ব্লার, শার্পেন, নয়েজ, পিক্সেলেট, এমবস, প্রান্ত শনাক্তকরণ, অয়েল
পেইন্টিং, ভিনেট। যেগুলোর সেটিংস আছে সেগুলো পরিবর্তনের সাথে সাথে ছবিতে প্রিভিউ দেখায়। নির্বাচন
থাকলে সমন্বয় ও ইফেক্ট শুধু সেই অংশেই প্রয়োগ হয়।

**ফাইল** — PNG, JPEG, WebP, GIF, BMP, SVG ও আরও অনেক ফরম্যাট খোলে; PNG, JPEG ও WebP ছবি সমতল
করে সংরক্ষণ করে। **OpenRaster (.ora)** লেয়ার রাখে, তাদের নাম, অস্বচ্ছতা, দৃশ্যমানতা ও ব্লেন্ড
মোড সহ — GIMP, Krita ও MyPaint-ও এটি খোলে। যেখানে ব্রাউজার পেজকে ফাইল লিখতে দেয় (Chrome, Edge),
সেখানে ⌘S / Ctrl+S খোলা ফাইলেই আবার সংরক্ষণ করে; অন্যত্র সংরক্ষণ মানেই ডাউনলোড।

## বিল্ড করুন

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # প্রতিটি পরিবর্তনে পুনর্নির্মাণ করে, আনমিনিফায়েড
npm run check        # টাইপচেক, ইউনিট টেস্ট, বিল্ড, ব্রাউজার টেস্ট
npm run shots        # shots/-এ প্রধান স্ক্রিনগুলোর স্ক্রিনশট
```

Node 20 বা তার পরের সংস্করণ। ব্রাউজার টেস্টগুলো DevTools প্রোটোকলের মাধ্যমে স্থানীয় Chrome-এ
তৈরি হওয়া পেজ চালায়; এটি অস্বাভাবিক জায়গায় থাকলে `CHROME=/path/to/chrome` সেট করুন।

বিল্ড `build/pages/`-ও লেখে: একই পেজ PWA হিসেবে — একটি ম্যানিফেস্ট, আইকন ও একটি সার্ভিস
ওয়ার্কার। এর PNG আইকনগুলো `assets/pwa/`-এ রাখা আছে; `src/app/icons.ts`-এর আইকন পরিবর্তনের পর,
`node tools/icons.mjs` সেগুলো (Chrome দিয়ে) আবার আঁকে।

## রিলিজ

GitHub Actions প্রকাশের কাজ করে:

- `main`-এ প্রতিটি push পরীক্ষিত হয়ে GitHub Pages-এ ডিপ্লয় হয় (Settings → Pages → Source:
  GitHub Actions, একবার);
- একটি `v<ভার্সন>` ট্যাগ `paint-v<ভার্সন>.html` ও তার `SHA256SUMS.txt` সহ একটি রিলিজ বিল্ড,
  পরীক্ষা ও প্রকাশ করে। ট্যাগটি অবশ্যই `package.json`-এর ভার্সনের সাথে মিলতে হবে:

  ```sh
  npm version 0.2.0      # package.json লেখে, কমিট করে, v0.2.0 ট্যাগ করে
  git push --follow-tags
  ```

## অনুবাদ

প্রতিটি দেখানো স্ট্রিং একটি সরল স্ট্রিং লিটারেল সহ `t('English text')` (অথবা ভাষা জানার আগে
যেখানে টেবিল তৈরি হয়, সেখানে `N_('…')`)। `node tools/i18n.mjs` প্রতিটি ডিকশনারিতে কী নেই বা আর
দরকার নেই তা তালিকাভুক্ত করে; `npm test` ব্যর্থ হয় যতক্ষণ না সেগুলো মিলে যায়। বহুবচনের মান একটি
অবজেক্ট, যেখানে ভাষার প্রতিটি বহুবচন বিভাগের (`one`, `few`, `many`, `other`…) জন্য একটি রূপ
থাকে। নতুন ভাষা মানে একটি নতুন `src/locales/<code>.json` এবং `src/app/language.ts`-এ একটি
লাইন।

এই README অনুবাদ করা হয় `docs/readme/README.<code>.md`-এ; `<!-- languages -->` চিহ্নের
মধ্যকার ভাষার তালিকা প্রতিটি অনুবাদে একই রকম।
