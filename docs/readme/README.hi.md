Paint.NET की शैली में एक इमेज एडिटर, **एक ही स्वतंत्र HTML फ़ाइल** के रूप में। लेयर, चयन,
समायोजन और इफ़ेक्ट, किसी भी चरण पर वापस जाने लायक हिस्ट्री — और कुछ भी इस पेज से बाहर नहीं
जाता: यह डिस्क से खुलता है, ऑफ़लाइन काम करता है, और नेटवर्क से कुछ भी लोड नहीं करता।

इंटरफ़ेस 17 भाषाओं में उपलब्ध है (देखें → भाषा…) — अंग्रेज़ी, चीनी, हिन्दी, स्पेनिश, फ़्रेंच,
अरबी, बंगाली, पुर्तगाली, रूसी, उर्दू, इंडोनेशियाई, जर्मन, जापानी, मराठी, तेलुगु, तुर्की और
यूक्रेनी; अरबी और उर्दू दाएँ से बाएँ चलते हैं। यह हल्की या गहरी थीम में आता है, और फ़ोन की
स्क्रीन पर भी उतना ही फ़िट बैठता है जितना डेस्कटॉप पर।

## इसे इस्तेमाल करें

[रिलीज़](https://github.com/MarketKernel/html-paint/releases) पेज से `paint-v<version>.html`
डाउनलोड करें, या इसे खुद बनाएँ (नीचे देखें), और इसे किसी ब्राउज़र में खोलें — Chrome, Edge,
Firefox या Safari। वह एक फ़ाइल ही पूरा प्रोग्राम है: इसे कहीं भी कॉपी करें, मेल करें, USB
स्टिक पर रखें।

या इसे [GitHub Pages](https://marketkernel.github.io/html-paint/) पर खोलें और ऐप की तरह
इंस्टॉल करें (एड्रेस बार में इंस्टॉल बटन; iPhone पर Share → Add to Home Screen)। इसके बाद यह
ऑफ़लाइन काम करता है, और नई डिप्लॉय के बाद अगली बार शुरू होने पर खुद अपडेट हो जाता है।

किसी इमेज को विंडो पर छोड़ें ताकि वह खुल जाए, या इस इमेज में लेयर के रूप में जुड़ जाए।

## यह क्या करता है

**टूल** — हर एक की अपनी कुंजी; उसे फिर दबाने पर उसी कुंजी के अगले टूल पर जाता है।

| टूल | कुंजी | |
|---|---|---|
| आयत, अंडाकार चयन और लैसो | S | Shift चयन में जोड़ता है, Alt घटाता है, दोनों मिलकर प्रतिच्छेदन |
| मैजिक वैंड | W | मिलते-जुलते रंग, सन्निहित या पूरी इमेज में, टॉलरेंस के हिसाब से |
| चयनित पिक्सेल ले जाएँ | M | खींचने पर ले जाता है, हैंडल आकार बदलते हैं, बाहर खींचने पर घुमाव; Enter लागू करता है, Esc वापस कर देता है |
| चयन ले जाएँ | M | सिर्फ़ रूपरेखा; ऐरो कुंजियाँ थोड़ा खिसकाती हैं |
| ज़ूम, पैन | Z, H | स्पेस या मध्य बटन किसी भी टूल से पैन करता है; ⌘/Ctrl + व्हील या पिंच ज़ूम करता है |
| पेंटब्रश | B | चौड़ाई, कठोरता, अपारदर्शिता, एंटीअलायज़िंग; पेन का दबाव |
| पेंसिल | P | एक-एक पिक्सेल |
| इरेज़र | E | |
| एयरब्रश | A | बटन दबाए रखने तक स्प्रे करता है |
| पेंट बकेट | F | टॉलरेंस, सन्निहित या पूरी इमेज में, लेयर या पूरी इमेज |
| ग्रेडिएंट | G | लीनियर, परावर्तित, रेडियल, शंक्वाकार; प्राइमरी से सेकेंडरी रंग तक |
| कलर पिकर | K | लेयर से या पूरी इमेज से; पिछले टूल पर वापस जा सकता है |
| क्लोन स्टैंप | L | Ctrl+क्लिक (⌘+क्लिक) स्रोत चुनता है |
| टेक्स्ट | T | जगह पर ही टाइप होता है; फ़ॉन्ट, आकार, बोल्ड, इटैलिक, अंडरलाइन, संरेखण |
| रेखा, आयत, अंडाकार | O | रूपरेखा, भरावट या दोनों; डैश, गोल कोने, तीर; Shift सीमित करता है |
| कर्व | O | बेज़ियर कर्व: लाइन खींचें, उसके दो नियंत्रण बिंदुओं से मोड़ें; Enter लागू करता है |

बायाँ बटन प्राइमरी रंग से रंग लगाता है, दायाँ सेकेंडरी रंग से। X दोनों की अदला-बदली करता है,
D दोनों को काले-सफ़ेद पर वापस लाता है, `[` और `]` ब्रश का आकार बदलते हैं।

**लेयर** — जोड़ना, हटाना, डुप्लिकेट करना, नीचे वाली से मर्ज करना, क्रम बदलना (पैनल में
खींचकर), छिपाना, नाम बदलना; अपारदर्शिता और 17 ब्लेंड मोड (मल्टिप्लाई, स्क्रीन, ओवरले, सॉफ्ट
लाइट, डिफ़रेंस, ह्यू…)।

**संपादन** — हर चरण का अनडू और रीडू, किसी भी चरण पर जाने के लिए हिस्ट्री पैनल के साथ; काटना,
कॉपी करना, मर्ज करके कॉपी करना; लेयर में पेस्ट करना (फ़्लोटिंग, ताकि उसे जगह पर रखा जा सके),
नई लेयर में या नई इमेज के रूप में — सिस्टम क्लिपबोर्ड से भी; सभी चुनना, चयन हटाना, चयन उलटना;
चयन मिटाना या भरना।

**इमेज** — चयन के अनुसार क्रॉप करना, आकार बदलना (स्मूद या नियरेस्ट नेबर), एंकर के साथ कैनवस
का आकार, फ़्लिप, घुमाव, लेयर समतल करना।

**समायोजन** — ऑटो-लेवल, काला और सफ़ेद, चमक और कंट्रास्ट, ह्यू और सैचुरेशन, रंग उलटना,
पोस्टराइज़, सीपिया, थ्रेशोल्ड।

**इफ़ेक्ट** — गाउसियन ब्लर, मोशन ब्लर, शार्पनिंग, नॉइज़, पिक्सेलेशन, एम्बॉस, एज डिटेक्ट, ऑइल
पेंटिंग, विनेट। जिनमें सेटिंग होती हैं वे बदलाव करते ही इमेज पर प्रीव्यू दिखाते हैं। समायोजन
और इफ़ेक्ट चयन होने पर उसी तक सीमित रहते हैं।

**फ़ाइलें** — PNG, JPEG, WebP, GIF, BMP, SVG और कई अन्य फ़ॉर्मेट खुलते हैं; PNG, JPEG और WebP
इमेज को समतल करके सहेजते हैं। **OpenRaster (.ora)** लेयर को बनाए रखता है — उनके नाम,
अपारदर्शिता, दृश्यता और ब्लेंड मोड के साथ — इसे GIMP, Krita और MyPaint भी खोल सकते हैं। जहाँ
ब्राउज़र पेज को फ़ाइल में लिखने देता है (Chrome, Edge), वहाँ ⌘S / Ctrl+S खुली फ़ाइल में वापस
सहेजता है; बाकी जगह सहेजना एक डाउनलोड होता है।

## बिल्ड करें

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # हर बदलाव पर फिर से बनाता है, बिना मिनिफ़ाई किए
npm run check        # टाइपचेक, यूनिट टेस्ट, बिल्ड, ब्राउज़र टेस्ट
npm run shots        # मुख्य स्क्रीन के स्क्रीनशॉट shots/ में
```

Node 20 या उसके बाद का वर्शन चाहिए। ब्राउज़र टेस्ट, DevTools प्रोटोकॉल के ज़रिए बनी हुई पेज
को लोकल Chrome में चलाते हैं; अगर वह कहीं अलग जगह है तो `CHROME=/path/to/chrome` सेट करें।

बिल्ड `build/pages/` भी बनाता है: वही पेज PWA के रूप में — मैनिफ़ेस्ट, आइकन और एक सर्विस
वर्कर। इसके PNG आइकन `assets/pwa/` में रखे जाते हैं; `src/app/icons.ts` में आइकन बदलने के
बाद, `node tools/icons.mjs` उन्हें (Chrome की मदद से) फिर से बनाता है।

## रिलीज़

पब्लिश करने का काम GitHub Actions करता है:

- `main` पर हर पुश टेस्ट होकर GitHub Pages पर डिप्लॉय होता है (Settings → Pages → Source:
  GitHub Actions, एक बार सेट करना होता है);
- `v<version>` टैग बिल्ड, टेस्ट करता है और `paint-v<version>.html` व उसकी `SHA256SUMS.txt`
  के साथ रिलीज़ पब्लिश करता है। टैग `package.json` के वर्शन से मेल खाना चाहिए:

  ```sh
  npm version 0.2.0      # package.json लिखता है, कमिट करता है, v0.2.0 टैग लगाता है
  git push --follow-tags
  ```

## अनुवाद

हर दिखाई गई स्ट्रिंग एक `t('English text')` है (या `N_('…')`, जहाँ भाषा तय होने से पहले कोई
टेबल बनती है), जो एक सादे स्ट्रिंग लिटरल के साथ होती है। `node tools/i18n.mjs` बताता है कि
हर डिक्शनरी में क्या कमी है या अब क्या ज़रूरत नहीं; जब तक ये मेल नहीं खातीं, `npm test` फ़ेल
होता है। बहुवचन की वैल्यू एक ऑब्जेक्ट होती है, जिसमें भाषा की हर बहुवचन श्रेणी (`one`, `few`,
`many`, `other`…) के लिए एक रूप होता है। नई भाषा का मतलब है एक नया `src/locales/<code>.json`
और `src/app/language.ts` में एक लाइन।

यह README `docs/readme/README.<code>.md` में अनुवादित है; `<!-- languages -->` मार्कर के बीच
भाषाओं की सूची हर अनुवाद में एक जैसी है।
