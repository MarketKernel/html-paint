Paint.NET తరహాలో రూపొందించిన చిత్ర సంపాదకి, **ఒకే స్వతంత్ర HTML ఫైల్‌గా**. లేయర్లు, ఎంపికలు,
సర్దుబాట్లు, ఎఫెక్ట్‌లు, వెనక్కి అడుగు వేసుకోగలిగే చరిత్ర — మరియు ఏదీ ఈ పేజీ నుండి బయటకు
వెళ్లదు: ఇది డిస్క్ నుండి తెరుచుకుంటుంది, ఆఫ్‌లైన్‌లో పనిచేస్తుంది, నెట్‌వర్క్ నుండి ఏమీ
లోడ్ చేయదు.

ఇంటర్‌ఫేస్ 17 భాషల్లో అందుబాటులో ఉంది (వీక్షణ → భాష…) — ఇంగ్లీష్, చైనీస్, హిందీ, స్పానిష్,
ఫ్రెంచ్, అరబిక్, బెంగాలీ, పోర్చుగీస్, రష్యన్, ఉర్దూ, ఇండోనేషియన్, జర్మన్, జపనీస్, మరాఠీ,
తెలుగు, టర్కిష్, ఉక్రేనియన్; అరబిక్, ఉర్దూ కుడి నుండి ఎడమకు ఉంటాయి. ఇది లైట్ లేదా డార్క్
థీమ్‌లో వస్తుంది, ఫోన్ తెరకు, డెస్క్‌టాప్‌కు రెండింటికీ సరిపోతుంది.

## ఎలా వాడాలి

[విడుదలల](https://github.com/MarketKernel/html-paint/releases) పేజీ నుండి
`paint-v<version>.html`ను డౌన్‌లోడ్ చేయండి, లేదా దాన్ని మీరే బిల్డ్ చేయండి (కింద చూడండి),
బ్రౌజర్‌లో తెరవండి — Chrome, Edge, Firefox లేదా Safari. ఆ ఒక్క ఫైలే మొత్తం ప్రోగ్రామ్:
దాన్ని ఎక్కడికైనా కాపీ చేయవచ్చు, మెయిల్ చేయవచ్చు, USB స్టిక్‌లో పెట్టవచ్చు.

లేదా దాన్ని [GitHub Pages](https://marketkernel.github.io/html-paint/)లో తెరిచి యాప్‌గా
ఇన్‌స్టాల్ చేయండి (అడ్రస్ బార్‌లో ఇన్‌స్టాల్ బటన్; iPhoneలో షేర్ → Add to Home Screen).
అప్పటి నుండి ఇది ఆఫ్‌లైన్‌లో పనిచేస్తుంది, కొత్త డిప్లాయ్ తర్వాత తదుపరి ప్రారంభంలో తనంతట
తానే అప్‌డేట్ అవుతుంది.

విండో మీద ఒక చిత్రాన్ని వదిలితే అది తెరుచుకుంటుంది, లేదా లేయర్‌గా జోడించబడుతుంది.

ఎడమ బటన్ ప్రాథమిక రంగుతో గీస్తుంది, కుడి బటన్ ద్వితీయ రంగుతో. X వాటిని మార్చుకుంటుంది, D
వాటిని నలుపు-తెలుపుకు రీసెట్ చేస్తుంది, `[` మరియు `]` బ్రష్ సైజును మారుస్తాయి.

**లేయర్లు** — జోడించడం, తొలగించడం, నకిలీ చేయడం, కింది దానితో విలీనం చేయడం, క్రమాన్ని
మార్చడం (ప్యానెల్‌లో డ్రాగ్ చేసి), దాచడం, పేరు మార్చడం; అపారదర్శకత, 17 బ్లెండ్ మోడ్‌లు
(గుణకారం, స్క్రీన్, ఓవర్‌లే, సాఫ్ట్ లైట్, డిఫరెన్స్, హ్యూ…).

**సవరించు** — ప్రతి దశకూ రద్దు, మళ్లీ చేయడం, వేటికైనా దూకడానికి చరిత్ర ప్యానెల్‌తో;
కత్తిరించడం, కాపీ చేయడం, విలీనం చేసి కాపీ చేయడం; లేయర్‌లో అతికించడం (తేలియాడుతూ,
సరిచేర్చుకోవడానికి), కొత్త లేయర్‌లో లేదా కొత్త చిత్రంగా — సిస్టమ్ క్లిప్‌బోర్డ్ నుండి కూడా;
అన్నీ ఎంచుకోవడం, ఎంపిక తొలగించడం, ఎంపికను విలోమం చేయడం; ఎంపికను చెరపడం లేదా నింపడం.

**చిత్రం** — ఎంపికకు క్రాప్ చేయడం, పరిమాణం మార్చడం (నునుపైన లేదా సమీప పొరుగు పద్ధతిలో),
యాంకర్‌తో కాన్వాస్ పరిమాణం, ఫ్లిప్ చేయడం, తిప్పడం, చదును చేయడం.

**సర్దుబాట్లు** — ఆటో-లెవెల్, నలుపు-తెలుపు, ప్రకాశం మరియు కాంట్రాస్ట్, హ్యూ మరియు
సంతృప్తత, రంగులను విలోమం చేయడం, పోస్టరైజ్, సెపియా, థ్రెషోల్డ్.

**ఎఫెక్ట్‌లు** — గాసియన్ బ్లర్, మోషన్ బ్లర్, షార్ప్, నాయిస్, పిక్సలేట్, ఎంబాస్, అంచు
గుర్తింపు, ఆయిల్ పెయింటింగ్, విగ్నెట్. సెట్టింగులు ఉన్నవి మీరు వాటిని మార్చినప్పుడు
చిత్రంపైనే ప్రివ్యూ చూపిస్తాయి. ఎంపిక ఉన్నప్పుడు సర్దుబాట్లు, ఎఫెక్ట్‌లు దానికే
పరిమితమవుతాయి.

**ఫైళ్లు** — PNG, JPEG, WebP, GIF, BMP, SVG మరియు మరిన్ని తెరుచుకుంటాయి; PNG, JPEG, WebP
చిత్రాన్ని చదును చేసి సేవ్ చేస్తాయి. **OpenRaster (.ora)** లేయర్లను వాటి పేర్లు,
అపారదర్శకత, కనిపించడం, బ్లెండ్ మోడ్‌లతో సహా ఉంచుతుంది — దీన్ని GIMP, Krita, MyPaint కూడా
తెరవగలవు. బ్రౌజర్ పేజీని ఫైళ్లు రాయనిచ్చే చోట (Chrome, Edge), ⌘S / Ctrl+S తెరిచిన
ఫైల్‌కే తిరిగి సేవ్ చేస్తుంది; మిగతా చోట్ల సేవ్ చేయడం అంటే డౌన్‌లోడ్ చేయడమే.

## బిల్డ్

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # ప్రతి మార్పుకూ మళ్లీ బిల్డ్ చేస్తుంది, మినిఫై చేయకుండా
npm run check        # టైప్‌చెక్, యూనిట్ టెస్ట్‌లు, బిల్డ్, బ్రౌజర్ టెస్ట్‌లు
npm run shots        # ప్రధాన స్క్రీన్‌ల స్క్రీన్‌షాట్‌లు shots/‌లోకి
```

Node 20 లేదా తర్వాతది కావాలి. బ్రౌజర్ టెస్ట్‌లు DevTools ప్రోటోకాల్ ద్వారా స్థానిక
Chromeలో బిల్డ్ చేసిన పేజీని నడుపుతాయి; అది అసాధారణ స్థానంలో ఉంటే
`CHROME=/path/to/chrome` సెట్ చేయండి.

బిల్డ్ `build/pages/`ను కూడా రాస్తుంది: అదే పేజీ PWAగా — మానిఫెస్ట్, ఐకాన్లు, సర్వీస్
వర్కర్‌తో. దాని PNG ఐకాన్లు `assets/pwa/`లో ఉంటాయి; `src/app/icons.ts`లోని ఐకాన్ మారిన
తర్వాత, `node tools/icons.mjs` వాటిని (Chrome సహాయంతో) మళ్లీ గీస్తుంది.

## విడుదలలు

ప్రచురణను GitHub Actions చూసుకుంటుంది:

- `main`కు ప్రతి పుష్ పరీక్షించి GitHub Pagesలో డిప్లాయ్ చేయబడుతుంది (Settings → Pages →
  Source: GitHub Actions, ఒకసారి మాత్రమే);
- `v<version>` ట్యాగ్ బిల్డ్ చేసి, పరీక్షించి, `paint-v<version>.html`తో పాటు దాని
  `SHA256SUMS.txt`తో సహా ఒక విడుదలను ప్రచురిస్తుంది. ఈ ట్యాగ్ తప్పనిసరిగా
  `package.json` వెర్షన్‌తో సరిపోలాలి:

  ```sh
  npm version 0.2.0      # package.jsonను రాస్తుంది, కమిట్ చేస్తుంది, v0.2.0 ట్యాగ్ పెడుతుంది
  git push --follow-tags
  ```

## అనువాదాలు

చూపించే ప్రతి స్ట్రింగ్ ఒక `t('English text')` (లేదా భాష తెలియకముందే టేబుల్ కట్టే చోట
`N_('…')`), సాదా స్ట్రింగ్ లిటరల్‌తో. `node tools/i18n.mjs` ప్రతి డిక్షనరీలో ఏది లేదో,
ఇక అవసరం లేనిది ఏదో చూపిస్తుంది; అవి సరిపోయేదాకా `npm test` విఫలమవుతుంది. బహువచనపు
విలువ భాష యొక్క ప్రతి బహువచన కేటగిరీకి (`one`, `few`, `many`, `other`…) ఒక రూపంతో కూడిన
ఆబ్జెక్ట్. కొత్త భాష అంటే కొత్త `src/locales/<code>.json` మరియు `src/app/language.ts`లో
ఒక లైన్.

ఈ README `docs/readme/README.<code>.md`లో అనువదించబడింది; `<!-- languages -->` గుర్తుల
మధ్య ఉన్న భాషల జాబితా అన్నింట్లో ఒకేలా ఉంటుంది.
