Редактор изображений в духе Paint.NET, в виде **одного самостоятельного HTML-файла**. Слои,
выделения, коррекция и эффекты, история с откатом к любому шагу — и ничего не покидает
страницу: он открывается с диска, работает без подключения и ничего не загружает из сети.

Интерфейс доступен на 17 языках (Вид → Язык…) — английском, китайском, хинди, испанском,
французском, арабском, бенгальском, португальском, русском, урду, индонезийском, немецком,
японском, маратхи, телугу, турецком и украинском; арабский и урду — справа налево. Есть
светлая и тёмная темы, а раскладка подстраивается и под экран телефона, и под рабочий стол.

## Как пользоваться

Скачайте `paint-v<версия>.html` со страницы
[релизов](https://github.com/MarketKernel/html-paint/releases) или соберите его сами (ниже)
и откройте в браузере — Chrome, Edge, Firefox или Safari. Это один файл — вся программа:
его можно скопировать куда угодно, отправить по почте, записать на флешку.

Либо откройте его на [GitHub Pages](https://marketkernel.github.io/html-paint/) и
установите как приложение (кнопка установки в адресной строке; на iPhone — «Поделиться» →
«На экран "Домой"»). После этого он работает офлайн и обновляется сам при следующем
запуске после нового выпуска.

Перетащите изображение на окно, чтобы открыть его или добавить слоем.

## Что он умеет

**Инструменты** — у каждого своя клавиша; повторное нажатие переключает на следующий
инструмент той же клавиши.

| Инструмент | Клавиша | |
|---|---|---|
| Прямоугольное, овальное выделение и лассо | S | Shift добавляет к выделению, Alt вычитает, вместе — пересечение |
| Волшебная палочка | W | Похожие цвета, смежные или по всему изображению, по допуску |
| Перемещение выделенного | M | Перетаскивание двигает, маркеры масштабируют, снаружи — поворот; Enter применяет, Esc возвращает обратно |
| Перемещение выделения | M | Только контур; стрелки сдвигают на пиксель |
| Масштаб, рука | Z, H | Пробел или средняя кнопка панорамируют с любым инструментом; ⌘/Ctrl + колесо или щипок масштабируют |
| Кисть | B | Ширина, жёсткость, непрозрачность, сглаживание; нажим пера |
| Карандаш | P | Отдельные пиксели |
| Ластик | E | |
| Распылитель | A | Распыляет, пока зажата кнопка |
| Заливка | F | Допуск, смежная область или по всему изображению, слой целиком или всё изображение |
| Градиент | G | Линейный, отражённый, радиальный, конический; от основного цвета к дополнительному |
| Пипетка | K | С текущего слоя или со всего изображения; может вернуться к прежнему инструменту |
| Штамп | L | Ctrl+клик (⌘+клик) задаёт источник |
| Текст | T | Печатается прямо на месте; шрифт, размер, жирный, курсив, подчёркнутый, выравнивание |
| Линия, прямоугольник, эллипс | O | Контур, заливка или и то и другое; штрихи, скруглённые углы, стрелки; Shift ограничивает |
| Кривая | O | Кривая Безье: протяните линию, согните её двумя опорными точками; Enter применяет |

Левая кнопка рисует основным цветом, правая — дополнительным. X меняет их местами, D
сбрасывает оба в чёрный и белый, `[` и `]` меняют размер кисти.

**Слои** — добавление, удаление, дублирование, объединение с нижним, изменение порядка
(перетаскиванием в панели), скрытие, переименование; непрозрачность и 17 режимов
наложения (умножение, экран, перекрытие, мягкий свет, разница, цветовой тон…).

**Правка** — отмена и повтор любого шага, с панелью истории для перехода к любому из них;
вырезать, копировать, копировать сведённое; вставка в слой (плавающим фрагментом, чтобы
разместить его), в новый слой или как новое изображение — в том числе из системного
буфера обмена; выделить всё, снять выделение, инвертировать выделение; стереть или
заполнить выделенную область.

**Изображение** — обрезка по выделению, изменение размера (сглаженное или методом
ближайшего соседа), размер холста с привязкой, отражение, поворот, сведение слоёв.

**Коррекция** — автоуровни, чёрно-белое, яркость и контраст, цветовой тон и насыщенность,
инвертировать цвета, постеризация, сепия, порог.

**Эффекты** — размытие по Гауссу, размытие в движении, резкость, шум, пикселизация,
тиснение, выделение краёв, масляная живопись, виньетка. Эффекты с настройками
показывают предпросмотр прямо на изображении по мере изменения параметров. Коррекция и
эффекты применяются только к выделенной области, если она есть.

**Файлы** — PNG, JPEG, WebP, GIF, BMP, SVG и другие форматы открываются; PNG, JPEG и WebP
сохраняют изображение сведённым. **OpenRaster (.ora)** сохраняет слои — с их именами,
непрозрачностью, видимостью и режимами наложения, — его также открывают GIMP, Krita и
MyPaint. Там, где браузер позволяет странице записывать файлы (Chrome, Edge), ⌘S / Ctrl+S
сохраняет обратно в открытый файл; в остальных случаях сохранение — это скачивание.

## Сборка

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # пересобирает при каждом изменении, без минификации
npm run check        # проверка типов, модульные тесты, сборка, браузерные тесты
npm run shots        # скриншоты основных экранов в shots/
```

Node 20 или новее. Браузерные тесты управляют собранной страницей в локальном Chrome
через протокол DevTools; если он лежит не на обычном месте, укажите
`CHROME=/path/to/chrome`.

Сборка также создаёт `build/pages/`: ту же страницу как PWA — манифест, иконки и
service worker. Её PNG-иконки хранятся в `assets/pwa/`; после изменения иконки в
`src/app/icons.ts` команда `node tools/icons.mjs` перерисовывает их заново (с помощью
Chrome).

## Релизы

Публикацией занимается GitHub Actions:

- каждый push в `main` тестируется и разворачивается на GitHub Pages (Settings → Pages →
  Source: GitHub Actions, один раз);
- тег `v<версия>` собирает, тестирует и публикует релиз с `paint-v<версия>.html` и его
  `SHA256SUMS.txt`. Тег должен совпадать с версией в `package.json`:

  ```sh
  npm version 0.2.0      # записывает package.json, коммитит, ставит тег v0.2.0
  git push --follow-tags
  ```

  core/            без DOM, выполняется в Node под тестами
    color.ts       RGB, HSV, HSL, hex; расстояние между цветами; палитра
    raster.ts      заливка (ведро, палочка), линии карандаша, контуры масок, прямоугольники
    filters.ts     коррекция и эффекты, на обычных массивах пикселей
    zip.ts, ora.ts ZIP и stack.xml формата OpenRaster

  app/             сама страница

    main.ts        запускает всё
    app.ts         состояние: документ, история, цвета, настройки, живой предпросмотр
    document.ts    изображение и его слои
    selection.ts   выделения как маски
    history.ts     отмена и повтор
    view.ts        рабочая область: масштаб, прокрутка, рисование, ввод с указателя
    tools/         по файлу на каждый вид инструмента
    commands.ts    меню и клавиатурные сочетания
    ops.ts         команды меню «Правка», «Изображение» и «Слои»

    io.ts          открытие и сохранение
    prompts.ts     диалоги за командами
    ui/            строка меню, панель инструментов, панели, диалоги
  locales/         ru.json, uk.json — по ключу английского текста
  pwa/sw.js        service worker сборки для GitHub Pages
assets/pwa/        PNG-иконки PWA
tests/             модульные тесты (Node) и браузерный тест (tests/app.mjs)
tools/             load.mjs (компилирует src/ для тестов), i18n.mjs (находит строки),

## Переводы

Каждая показанная строка — это `t('English text')` (или `N_('…')` там, где таблица
строится до того, как известен язык) с простым строковым литералом. `node tools/i18n.mjs`
покажет, чего не хватает в каждом словаре или что в нём больше не нужно; `npm test` не
проходит, пока они не совпадут. Значение множественного числа — это объект с формой для
каждой категории множественного числа языка (`one`, `few`, `many`, `other`…). Новый язык —
это новый `src/locales/<code>.json` и строка в `src/app/language.ts`.

Этот README переведён в `docs/readme/README.<code>.md`; список языков между метками
`<!-- languages -->` одинаков в каждом переводе.
