Paint.NET کے انداز میں ایک تصویر ایڈیٹر، بطور **ایک خودمختار HTML فائل**۔ تہیں، انتخاب، درستگیاں
اور اثرات، ایک تاریخچہ جس میں آپ پیچھے جا سکتے ہیں — اور کچھ بھی صفحے سے باہر نہیں جاتا: یہ ڈسک
سے کھلتا ہے، آف لائن کام کرتا ہے، اور نیٹ ورک سے کچھ بھی لوڈ نہیں کرتا۔

انٹرفیس 17 زبانوں میں دستیاب ہے (منظر → زبان…) — انگریزی، چینی، ہندی، ہسپانوی، فرانسیسی، عربی،
بنگالی، پرتگالی، روسی، اردو، انڈونیشیائی، جرمن، جاپانی، مراٹھی، تیلگو، ترکی اور یوکرینی؛ عربی اور
اردو دائیں سے بائیں۔ یہ ہلکی یا گہری تھیم میں آتا ہے، اور موبائل کی اسکرین کے ساتھ ساتھ ڈیسک ٹاپ
پر بھی فٹ ہوتا ہے۔

## استعمال کریں

`paint-v<version>.html` کو [ریلیزز](https://github.com/MarketKernel/html-paint/releases) سے
ڈاؤن لوڈ کریں، یا اسے خود بنائیں (نیچے ملاحظہ کریں)، اور کسی براؤزر میں کھولیں — Chrome، Edge،
Firefox یا Safari۔ یہ ایک فائل ہی پورا پروگرام ہے: اسے کہیں بھی کاپی کریں، ای میل کریں، USB اسٹک
پر رکھیں۔

یا اسے [GitHub Pages](https://marketkernel.github.io/html-paint/) پر کھولیں اور ایپ کے طور پر
انسٹال کریں (ایڈریس بار میں انسٹال بٹن؛ آئی فون پر Share → Add to Home Screen)۔ اس کے بعد یہ
آف لائن کام کرتا ہے، اور نئی ڈیپلائے کے بعد اگلی بار شروع ہونے پر خود بخود اپڈیٹ ہو جاتا ہے۔

تصویر کو ونڈو پر ڈراپ کریں تاکہ اسے کھولا جائے، یا اسے بطور تہہ شامل کیا جائے۔

## یہ کیا کرتا ہے

**اوزار** — ہر ایک کی اپنی کلید ہے؛ دوبارہ دبانے سے اسی کلید کے اگلے اوزار پر چلا جاتا ہے۔

| اوزار | کلید | |
|---|---|---|
| مستطیل، بیضوی اور لاسو انتخاب | S | Shift انتخاب میں اضافہ کرتا ہے، Alt نکالتا ہے، دونوں ایک ساتھ تقاطع کرتے ہیں |
| جادوئی چھڑی | W | ملتے جلتے رنگ، متصل یا پوری تصویر میں، رواداری کے حساب سے |
| منتخب پکسلز کو منتقل کریں | M | گھسیٹ کر منتقل کریں، ہینڈلز سے حجم بدلیں، باہر سے گھمائیں؛ Enter لاگو کرتا ہے، Esc واپس کر دیتا ہے |
| انتخاب منتقل کریں | M | صرف خاکہ؛ تیر والی کلیدیں تھوڑا سا سرکاتی ہیں |
| زوم، ہاتھ | Z, H | کسی بھی اوزار سے اسپیس یا درمیانی بٹن منظر سرکاتا ہے؛ ⌘/Ctrl + وہیل یا پنچ زوم کرتا ہے |
| برش | B | چوڑائی، سختی، اوپیسٹی، اینٹی الائزنگ؛ قلم کا دباؤ |
| پنسل | P | اکیلے پکسل |
| ایریزر | E | |
| ایئر برش | A | بٹن دبائے رکھنے پر چھڑکتا ہے |
| رنگ کی بالٹی | F | رواداری، متصل یا پوری تصویر، تہہ یا پوری تصویر |
| میلان | G | خطی، منعکس، شعاعی، مخروطی؛ بنیادی → ثانوی رنگ |
| کلر پکر | K | تہہ یا تصویر سے؛ پچھلے اوزار پر واپس جا سکتا ہے |
| کلون اسٹیمپ | L | Ctrl+کلک (⌘+کلک) ماخذ منتخب کرتا ہے |
| متن | T | جگہ پر لکھا جاتا ہے؛ فونٹ، حجم، بولڈ، ترچھا، زیرِ خط، سیدھ |
| لکیر، مستطیل، بیضہ | O | خاکہ، بھرائی یا دونوں؛ دھاریاں، گول کونے، تیر؛ Shift پابند کرتا ہے |
| خم | O | ایک بیزیئر خم: لکیر گھسیٹیں، اس کے دو کنٹرول پوائنٹس سے موڑیں؛ Enter لاگو کرتا ہے |

بایاں بٹن بنیادی رنگ سے رنگ کرتا ہے، دایاں ثانوی رنگ سے۔ X انہیں تبدیل کرتا ہے، D انہیں سیاہ اور
سفید پر واپس لے جاتا ہے، `[` اور `]` برش کا حجم بدلتے ہیں۔

**تہیں** — شامل کریں، حذف کریں، نقل بنائیں، نیچے ضم کریں، ترتیب بدلیں (پینل میں گھسیٹ کر)، چھپائیں،
نام بدلیں؛ اوپیسٹی اور 17 بلینڈ موڈز (ضرب، اسکرین، اوورلے، نرم روشنی، فرق، رنگت…)۔

**ترمیم** — ہر قدم کو کالعدم اور دوبارہ کریں، تاریخچہ پینل کے ذریعے کسی بھی قدم پر جائیں؛ کاٹیں،
کاپی کریں، ضم شدہ کاپی کریں؛ تہہ میں چسپاں کریں (تیرتا ہوا، جگہ پر رکھنے کے لیے)، نئی تہہ میں یا
نئی تصویر کے طور پر — سسٹم کے کلپ بورڈ سے بھی؛ سب منتخب کریں، انتخاب ختم کریں، انتخاب الٹ دیں؛
انتخاب مٹائیں یا بھریں۔

**تصویر** — انتخاب تک تراشیں، حجم تبدیل کریں (ہموار یا قریب ترین ہمسایہ)، اینکر کے ساتھ کینوس کا
حجم، الٹائیں، گھمائیں، تہیں یکجا کریں۔

**درستگیاں** — خودکار سطحیں، سیاہ و سفید، چمک اور تضاد، رنگت اور اشباع، رنگ الٹ دیں، پوسٹرائز،
سیپیا، حد۔

**اثرات** — گاؤسی دھندلاپن، حرکتی دھندلاپن، تیز کریں، شور، پکسلیٹ، ابھار، کناروں کی شناخت، تیل کی
پینٹنگ، ویگنیٹ۔ جن کی ترتیبات ہوتی ہیں وہ تبدیل کرتے ہی تصویر پر پیش منظر دکھاتی ہیں۔ جب کوئی
انتخاب موجود ہو تو درستگیاں اور اثرات اسی تک محدود رہتے ہیں۔

**فائلیں** — PNG، JPEG، WebP، GIF، BMP، SVG اور مزید کھلتی ہیں؛ PNG، JPEG اور WebP تصویر کو یکجا
کر کے محفوظ کرتے ہیں۔ **OpenRaster (.ora)** تہیں، ان کے ناموں، اوپیسٹی، مرئیت اور بلینڈ موڈز کے
ساتھ محفوظ رکھتا ہے — GIMP، Krita اور MyPaint بھی اسے کھولتے ہیں۔ جہاں براؤزر کسی صفحے کو فائل
لکھنے دیتا ہے (Chrome، Edge)، وہاں ⌘S / Ctrl+S کھلی ہوئی فائل میں ہی محفوظ کرتا ہے؛ باقی جگہوں پر
محفوظ کرنا ڈاؤن لوڈ ہوتا ہے۔

## تعمیر

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # ہر تبدیلی پر دوبارہ تعمیر کرتا ہے، بغیر میینیفائی کیے
npm run check        # ٹائپ چیک، یونٹ ٹیسٹ، تعمیر، براؤزر ٹیسٹ
npm run shots        # اہم اسکرینز کے اسکرین شاٹس shots/ میں
```

Node 20 یا بعد کا ورژن درکار ہے۔ براؤزر ٹیسٹ تیار شدہ صفحے کو مقامی Chrome میں DevTools پروٹوکول
کے ذریعے چلاتے ہیں؛ اگر یہ غیر معمولی جگہ پر ہو تو `CHROME=/path/to/chrome` مقرر کریں۔

تعمیر `build/pages/` بھی لکھتی ہے: وہی صفحہ بطور PWA — ایک مینی فیسٹ، آئیکنز اور ایک سروس ورکر۔
اس کے PNG آئیکنز `assets/pwa/` میں رکھے جاتے ہیں؛ `src/app/icons.ts` میں آئیکن بدلنے کے بعد،
`node tools/icons.mjs` انہیں (Chrome کے ساتھ) دوبارہ بناتا ہے۔

## ریلیزز

اشاعت GitHub Actions کرتا ہے:

- `main` پر ہر پش کو ٹیسٹ کیا جاتا ہے اور GitHub Pages پر ڈیپلائے کیا جاتا ہے (Settings → Pages →
  Source: GitHub Actions، ایک بار)؛
- ایک ٹیگ `v<version>` تعمیر کرتا ہے، ٹیسٹ کرتا ہے اور `paint-v<version>.html` اور اس کے
  `SHA256SUMS.txt` کے ساتھ ایک ریلیز شائع کرتا ہے۔ ٹیگ کا `package.json` کے ورژن سے ملنا ضروری
  ہے:

  ```sh
  npm version 0.2.0      # package.json لکھتا ہے، کمٹ کرتا ہے، v0.2.0 ٹیگ لگاتا ہے
  git push --follow-tags
  ```

```
  app/             صفحہ

    document.ts    تصویر اور اس کی تہیں

    history.ts     کالعدم اور دوبارہ
    view.ts        ورک اسپیس: زوم، سکرول، ڈرائنگ، پوائنٹر ان پٹ
    tools/         ہر قسم کے اوزار کے لیے ایک فائل
    commands.ts    مینیوز اور کی بورڈ شارٹ کٹس
    ops.ts         ترمیم، تصویر اور تہوں کے کمانڈز
    effects.ts     درستگیاں اور اثرات کے مینیو
    io.ts          کھولنا اور محفوظ کرنا
    prompts.ts     کمانڈز کے پیچھے ڈائیلاگ
    ui/            مینیو بار، ٹول باکس، پینل، ڈائیلاگ
  locales/         ru.json، uk.json — انگریزی متن سے کلید بند
  pwa/sw.js        GitHub Pages تعمیر کا سروس ورکر
assets/pwa/        PWA کے PNG آئیکنز
tests/             یونٹ ٹیسٹ (Node) اور براؤزر ٹیسٹ (tests/app.mjs)
tools/             load.mjs (ٹیسٹوں کے لیے src/ مرتب کرتا ہے)، i18n.mjs (متن ڈھونڈتا ہے)،
                   icons.mjs (assets/pwa/ بناتا ہے)
build.mjs          سب کچھ build/paint.html اور build/pages/ میں یکجا کرتا ہے
.github/workflows/ ٹیسٹ، GitHub Pages ڈیپلائے، v* ٹیگز سے ریلیزز
```

## تراجم

ہر دکھایا جانے والا متن ایک `t('English text')` ہے (یا `N_('…')` جہاں زبان معلوم ہونے سے پہلے کوئی
جدول بنایا جاتا ہے) اور ایک سادہ اسٹرنگ لٹرل کے ساتھ۔ `node tools/i18n.mjs` ہر ڈکشنری کی کمی یا اب
غیر ضروری اندراجات کی فہرست دیتا ہے؛ جب تک یہ ایک جیسے نہ ہوں `npm test` ناکام رہتا ہے۔ کسی جمع
(plural) کی قدر ایک آبجیکٹ ہوتی ہے جس میں زبان کے ہر جمع زمرے (`one`, `few`, `many`, `other`…) کے
لیے ایک شکل ہوتی ہے۔ نئی زبان کا مطلب ہے ایک نئی `src/locales/<code>.json` اور `src/app/language.ts`
میں ایک نئی سطر۔

یہ README ہر `docs/readme/README.<code>.md` میں ترجمہ کیا جاتا ہے؛ `<!-- languages -->` نشانات کے
درمیان زبانوں کی فہرست ہر جگہ ایک جیسی ہوتی ہے۔
