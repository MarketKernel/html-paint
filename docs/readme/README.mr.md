Paint.NET च्या शैलीतील इमेज एडिटर, **एकाच स्वयंपूर्ण HTML फाइलमध्ये**. लेयर, निवडी, समायोजन आणि
इफेक्ट्स, मागे जाता येईल असा इतिहास — आणि काहीही या पानाबाहेर जात नाही: ती डिस्कवरून उघडते,
ऑफलाइन चालते आणि नेटवर्कवरून काहीही लोड करत नाही.

इंटरफेस 17 भाषांमध्ये आहे (दृश्य → भाषा…) — इंग्रजी, चिनी, हिंदी, स्पॅनिश, फ्रेंच, अरबी, बंगाली,
पोर्तुगीज, रशियन, उर्दू, इंडोनेशियन, जर्मन, जपानी, मराठी, तेलुगू, तुर्की आणि युक्रेनियन; अरबी आणि
उर्दू उजवीकडून डावीकडे. हे फिकट किंवा गडद थीममध्ये येते आणि फोनच्या स्क्रीनवर तसेच डेस्कटॉपवरही
नीट बसते.

## वापरा

[releases](https://github.com/MarketKernel/html-paint/releases) मधून `paint-v<version>.html`
डाउनलोड करा, किंवा ती स्वतः बिल्ड करा (खाली), आणि ब्राउझरमध्ये उघडा — Chrome, Edge, Firefox किंवा
Safari. ती एकच फाइल म्हणजे संपूर्ण प्रोग्राम आहे: कुठेही कॉपी करा, मेल करा, USB स्टिकवर ठेवा.

किंवा ती [GitHub Pages](https://marketkernel.github.io/html-paint/) वर उघडा आणि अॅप म्हणून
इन्स्टॉल करा (अॅड्रेस बारमधील इन्स्टॉल बटण; iPhone वर Share → Add to Home Screen). त्यानंतर ती
ऑफलाइन चालते, आणि नवीन डिप्लॉयनंतर पुढच्या वेळी सुरू करताना स्वतःला अद्ययावत करते.

संगणकावरील Chrome आणि Edge मध्ये इन्स्टॉल केलेले अॅप सिस्टममधूनही चित्रे उघडते: PNG, JPEG,
WebP, GIF, BMP, ICO, AVIF, SVG किंवा OpenRaster फाइलसाठी Open With मध्ये ते निवडा, किंवा
त्याला डिफॉल्ट बनवा. प्रत्येक फाइल स्वतःच्या वेगळ्या विंडोमध्ये उघडते, आणि जतन केल्यावर
त्याच फाइलमध्ये लिहिले जाते.

प्रतिमा उघडण्यासाठी, किंवा लेयर म्हणून जोडण्यासाठी ती विंडोवर ड्रॉप करा.

## हे काय करते

**टूल्स** — प्रत्येकाची एक की; ती पुन्हा दाबल्यास त्याच कीवरील पुढील टूलकडे जाते.

| टूल | की | |
|---|---|---|
| आयत, अंडाकृती आणि लॅसो निवड | S | Shift निवडीत भर घालतो, Alt वजा करतो, दोन्ही मिळून छेदन |
| मॅजिक वँड | W | समान रंग, संलग्न किंवा संपूर्ण प्रतिमेत, टॉलरन्सनुसार |
| निवडलेले पिक्सेल हलवा | M | हलवण्यासाठी ड्रॅग, आकारासाठी हँडल्स, बाहेर फिरवण्यासाठी; Enter लागू करतो, Esc मागे ठेवतो |
| निवड हलवा | M | फक्त रूपरेषा; बाण की थोडे सरकवतात |
| झूम, पॅन | Z, H | कोणत्याही टूलसह स्पेस किंवा मधले बटण पॅन करते; ⌘/Ctrl + व्हील किंवा पिंच झूम करतो |
| पेंटब्रश | B | रुंदी, हार्डनेस, अपारदर्शकता, अँटीअलायझिंग; पेनचा दाब |
| पेन्सिल | P | एकेक पिक्सेल |
| इरेजर | E | |
| एअरब्रश | A | बटण दाबून ठेवल्यावर फवारते |
| पेंट बकेट | F | टॉलरन्स, संलग्न किंवा संपूर्ण, लेयर किंवा संपूर्ण प्रतिमा |
| ग्रेडियंट | G | रेषीय, परावर्तित, रेडियल, शंकाकृती; मुख्य → दुय्यम रंग |
| कलर पिकर | K | लेयरमधून किंवा प्रतिमेतून; आधीच्या टूलकडे परत जाऊ शकतो |
| क्लोन स्टॅम्प | L | Ctrl+क्लिक (⌘+क्लिक) स्रोत निवडतो |
| मजकूर | T | जागच्या जागी टाइप; फॉन्ट, आकार, ठळक, तिरपे, अधोरेखित, संरेखन |
| रेषा, आयत, अंडाकृती | O | रूपरेषा, भरणे किंवा दोन्ही; डॅश, गोलाकार कोपरे, बाण; Shift मर्यादित करतो |
| वक्र | O | बेझियर वक्र: रेषा ओढा, तिच्या दोन नियंत्रण बिंदूंनी वाकवा; Enter लागू करतो |

डावे बटण मुख्य रंगाने रंगवते, उजवे दुय्यम रंगाने. X ते अदलाबदल करतो, D काळ्या-पांढऱ्यावर रीसेट
करतो, `[` आणि `]` ब्रश आकार बदलतात.

**लेयर्स** — जोडा, हटवा, डुप्लिकेट करा, खाली विलीन करा, पुन्हा क्रमवारी लावा (पॅनेलमध्ये ड्रॅग
करून), लपवा, नाव बदला; अपारदर्शकता आणि 17 ब्लेंड मोड (मल्टिप्लाय, स्क्रीन, ओव्हरले, सॉफ्ट लाइट,
डिफरन्स, ह्यू…).

**संपादन** — प्रत्येक पायरीचे अन्डू आणि रीडू, त्यापैकी कोणत्याहीवर जाण्यासाठी इतिहास पॅनेल; कट,
कॉपी, एकत्र करून कॉपी; लेयरमध्ये चिकटवणे (तरंगते, जागेवर ठेवण्यासाठी), नवीन लेयरमध्ये किंवा नवीन
प्रतिमा म्हणून — सिस्टीमच्या क्लिपबोर्डमधूनही; सर्व निवडा, निवड रद्द करा, निवड उलटवा; निवड पुसा
किंवा भरा.

**प्रतिमा** — निवडीनुसार क्रॉप करा, आकार बदला (मऊ किंवा निअरेस्ट नेबर), अँकरसह कॅनव्हास आकार,
फ्लिप, फिरवा, सपाट करा.

**समायोजन** — ऑटो-लेव्हल, काळा-पांढरा, ब्राइटनेस आणि कॉन्ट्रास्ट, ह्यू आणि सॅच्युरेशन, रंग उलटवा,
पोस्टराइझ, सेपिया, थ्रेशोल्ड.

**इफेक्ट्स** — गॉसियन ब्लर, मोशन ब्लर, शार्पन, नॉइज, पिक्सेलेट, एम्बॉस, कडा शोधा, ऑइल पेंटिंग,
व्हिग्नेट. ज्यांना सेटिंग्ज आहेत ते बदलताच प्रतिमेवर पूर्वावलोकन दाखवतात. निवड असल्यास समायोजन
आणि इफेक्ट्स तिच्यापुरतेच मर्यादित राहतात.

**फाइल्स** — PNG, JPEG, WebP, GIF, BMP, SVG आणि अधिक उघडतात; PNG, JPEG आणि WebP प्रतिमा सपाट
करून जतन करतात. **OpenRaster (.ora)** लेयर, त्यांची नावे, अपारदर्शकता, दृश्यमानता आणि ब्लेंड मोड
यांसह ठेवते — GIMP, Krita आणि MyPaint मध्येही ती उघडते. ब्राउझर पानाला फाइल लिहू देत असेल तिथे
(Chrome, Edge) ⌘S / Ctrl+S उघडलेल्या फाइलमध्येच परत जतन करते; अन्यत्र जतन करणे म्हणजे डाउनलोड.

## बिल्ड

```sh
npm install
npm run build        # → build/paint.html
npm run watch        # प्रत्येक बदलावर पुन्हा बिल्ड होते, मिनिफाय न करता
npm run check        # टाइपचेक, युनिट टेस्ट, बिल्ड, ब्राउझर टेस्ट
npm run shots        # मुख्य स्क्रीन्सचे स्क्रीनशॉट shots/ मध्ये
```

Node 20 किंवा नवीन. ब्राउझर टेस्ट्स बिल्ड केलेले पान स्थानिक Chrome मध्ये DevTools प्रोटोकॉलवरून
चालवतात; Chrome असामान्य ठिकाणी असल्यास `CHROME=/path/to/chrome` सेट करा.

बिल्ड `build/pages/` देखील लिहिते: तेच पान PWA म्हणून — मॅनिफेस्ट, आयकॉन आणि एक सर्व्हिस वर्कर.
त्याचे PNG आयकॉन `assets/pwa/` मध्ये ठेवलेले आहेत; `src/app/icons.ts` मधील आयकॉन बदलल्यावर
`node tools/icons.mjs` ते पुन्हा काढतो (Chrome सह).

## रिलीज

GitHub Actions प्रकाशन करते:

- `main` वर प्रत्येक पुश टेस्ट होते आणि GitHub Pages वर डिप्लॉय होते (Settings → Pages → Source:
  GitHub Actions, एकदाच);
- `v<version>` टॅग बिल्ड, टेस्ट करतो आणि `paint-v<version>.html` व त्याची `SHA256SUMS.txt` असलेली
  रिलीज प्रकाशित करतो. टॅग `package.json` च्या आवृत्तीशी जुळला पाहिजे:

  ```sh
  npm version 0.2.0      # package.json लिहितो, कमिट करतो, v0.2.0 टॅग करतो
  git push --follow-tags
  ```

## भाषांतर

दाखवली जाणारी प्रत्येक स्ट्रिंग `t('English text')` आहे (किंवा भाषा ठरण्याआधी बनणाऱ्या टेबलसाठी
`N_('…')`), प्लेन स्ट्रिंग लिटरलसह. `node tools/i18n.mjs` प्रत्येक डिक्शनरीत काय कमी आहे किंवा
आता गरज नाही ते सांगतो; ते जुळेपर्यंत `npm test` अयशस्वी होते. बहुवचनाचे मूल्य भाषेच्या प्रत्येक
बहुवचन श्रेणीसाठी (`one`, `few`, `many`, `other`…) एक रूप असलेला ऑब्जेक्ट असते. नवीन भाषा म्हणजे
नवीन `src/locales/<code>.json` आणि `src/app/language.ts` मधील एक ओळ.

हा README `docs/readme/README.<code>.md` मध्ये भाषांतरित आहे; `<!-- languages -->` खुणांमधील
भाषांची यादी प्रत्येकात सारखीच आहे.
